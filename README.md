# DCP Camera Profile Spoofer

DCP Camera Profile Spoofer allows you to switch between Adobe Camera Match profiles by changing the camera name.

For example, the project describes using profiles such as CineLike A2, L Classic, and L Classic Gold, originally available for the S1 II and L10, with the S5 II and older cameras. It also describes compatibility with cameras from Sony, Canon, Nikon, and other brands. Results may vary by camera and profile.

## Download

The [DCP-Win 1.0 release](https://github.com/HongwenWang1976/DCP-Adobe-camera-match/releases/tag/1.0.0) includes a Windows installer, `DCP.Spoofer.Setup.1.0.0.exe`. Download it from the release page and run the installer.

## Camera compatibility

See the [supported camera list](supported_cameras.txt). For the best color results, the original project guidance recommends using cameras with the same CMOS sensor—for example, the Sony a7 III and Panasonic S5 both use the IMX410.
